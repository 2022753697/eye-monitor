# 眼互（EyeMonitor）出口验收清单 v1

> 依据：`.omc/specs/deep-interview-next-round.md`（P3 出口验收）+
> `.omc/specs/deep-interview-new-features.md`（2025-09 七组件 8 场景）
> 用途：双端真机走查逐场景打勾；**P0/P1 必修，P2 记录**。
> 环境要求：服务端运行**最新代码**（本轮所有服务端改动生效的前提）+ 双端安装最新 APK + 已登录并配对。

---

## 一、环境准备（走查前必做）

- [ ] 服务端重启：`mvn spring-boot:run`（server/）——确保 chat_read/chat_recall 落库、ChatController 新字段、围栏/媒体/账户全套在线
- [ ] 双端装最新 APK：MuMu 已装；真机 `adb install -r app-debug.apk`
- [ ] 双端登录同一账号体系并配对（6 位码）
- [ ] 位置注入工具：`adb emu geo fix <lng> <lat>`（MuMu/模拟器）
- [ ] 通知权限已授权（Android 13+）、监控服务前台通知可见

---

## 二、缺陷分级

| 级 | 定义 | 处置 |
|----|------|------|
| P0 | 崩溃 / 数据丢失 / 无法进入 App | 立即修 |
| P1 | 主要功能不生效或结果错误（双方不同步等） | 走查周期内修 |
| P2 | 体验/样式瑕疵、边界行为 | 记录清单，可延后 |
